# 长图句义复核来源

本次修订针对 `assets/cards/classic.png` 的问题：原先部分 token 使用了占位语句，无法承担经文翻译。现在改为按句群切分，把每一处原文先译成清楚的现代汉语，再按官方 `ljg-classic` 的版面宽度展开到相邻短语下方。句义不把现代感想冒充经文原意；“无、非、即非、是名”等表达保留佛典语境，译为“不是固定实有”“只是暂立的名称”等可复述的句义。

## 底本与校勘

- [CBETA T0235《金刚般若波罗蜜经》](https://tripitaka.zensoul.org/T/T0235/1)：用于确认鸠摩罗什译本、句读和版本异文。
- [维基文库《金刚般若波罗蜜经（鸠摩罗什）》](https://zh.wikisource.org/zh-hans/金剛般若波羅蜜經（鳩摩羅什）)：用于比对通行简体本的可读文本。

## 现代白话对照

- [金刚经网逐品译文·第一品](https://m.jingangjing.net/1.htm)：用于核对序分、乞食、洗足和敷座等基础句义。
- [金刚经网逐品译文·第三十二品](https://m.jingangjing.net/32.htm)：用于核对结尾四句偈和“信受奉行”的收束语义。

## 经典注疏与科判

- [《金刚经百家集注大成》](https://baus-ebs.org/sutra/jan-read/007/28.htm)：参考历代注家对经题、如是我闻、无住布施、四相、筏喻和“如梦幻泡影”等语句的解释。
- [吉藏《金刚般若疏》科判 PDF](https://www.kepanhuizong.org/lib/exe/fetch.php?media=b_9_04.pdf)：用于核对序分、正说分、无住行、信受、格量和流通等结构关系。

这些资料用于交叉核对，不把任何单一网站的现代发挥直接当成经文。最终长图的红色句义是本项目的学习译写，原文仍以 `data/classic.json` 和 `data/source-text.txt` 锁定的底本为准。
