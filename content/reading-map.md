# 《金刚经》结构伴读地图

三十二分是导航牌，不是原经的现代章节。第一次读全文时，不求一次把所有术语解释完，只跟住一条动作线：法会现场 → 善现发问 → 不住而行 → 反复拆相 → 功德与福德也不抓 → 菩萨、佛和法身都不可固定 → 以筏喻收束 → 信受奉行。

## 八站路线

| 站 | 分段 | 读什么 | 记忆动作 |
| --- | --- | --- | --- |
| 1. 现场 | 一至二分 | 佛陀乞食、敷座，须菩提发问 | 把抽象经义放回一碗饭、一方座 |
| 2. 发心 | 三至四分 | 度一切众生而不住相，布施也不住 | 做事，放下“我是施者”的奖章 |
| 3. 见相 | 五至八分 | 身相、声音、言说和功德都不能当成如来 | 看到一个相，补问“它是不是全部” |
| 4. 校验 | 九至十四分 | 四果、法、忍辱、受持与正信都经受拆解 | 让“我已懂”也接受一次检验 |
| 5. 功德 | 十五至十六分 | 持经、受持、读诵和过去业障的关系 | 记功劳而不把功劳变成身份 |
| 6. 无我 | 十七至二十四分 | 菩萨、庄严、福德、知见和善法不固定 | 每遇一个名词，追它的条件与用途 |
| 7. 非有非无 | 二十五至二十八分 | 众生、佛、福报和取法都不能执取 | 同时放下“只有”和“什么都没有” |
| 8. 收束 | 二十九至三十二分 | 威仪、微尘、世界、应化身，最后归于偈 | 如梦幻泡影，回到下一次行动 |

## 每一分的三个问题

1. 这一分正在拆哪一个“以为固定”的相？
2. 它保留了什么行动（布施、受持、发心、观察），又撤掉了什么占有感？
3. 我能不能用自己的一个日常场景说出这条关系，而不只复述术语？

读完一分后，在纸上留一句空白：**今天哪一个“相”被我过快地当成了全部？** 不必写正确答案，只写一个可观察的例子。

## 关键词链

`乞食 → 敷座 → 发心 → 无住 → 布施 → 身相非相 → 不应住色声香味触法 → 功德不取 → 四相不可得 → 忍辱与受持 → 无所得 → 一切有为法如梦幻泡影`

朗读时每遇箭头停一拍；遮盖原文时只保留这条链，再由关键词回填句群。前四站回答“怎样行动”，后四站回答“怎样不把行动、身份和结果抓死”。
