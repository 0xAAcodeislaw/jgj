# 无法可得分第二十二

须菩提白佛言：「世尊！佛得阿耨多罗三藐三菩提。为无所得耶？」佛言：「如是，如是。须菩提！我于阿耨多罗三藐三菩提乃至无有少法可得，是名阿耨多罗三藐三菩提。」

## 原文

须菩提白佛言：「世尊！佛得阿耨多罗三藐三菩提。为无所得耶？」佛言：「如是，如是。须菩提！我于阿耨多罗三藐三菩提乃至无有少法可得，是名阿耨多罗三藐三菩提。」

## 朗读停顿

须菩提白佛言：「世尊！ / 佛得阿耨多罗三藐三菩提。 / 为无所得耶？ / 」佛言：「如是，如是。 / 须菩提！ / 我于阿耨多罗三藐三菩提乃至无有少法可得，是名阿耨多罗三藐三菩提。 / 」

## 关键词链

无少法可得 → 无所得

## 句义

佛在无上正等正觉中乃至没有少法可得；‘得’在这里不能被理解为领取一件外来的奖品。

## 段落作用

[筋] 直接回答佛是否有所得：觉悟不可被当成一件新物品。
