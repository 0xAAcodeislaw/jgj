# 不受不贪分第二十八

「须菩提！若菩萨以满恒河沙等世界七宝持用布施；若复有人，知一切法无我，得成于忍，此菩萨胜前菩萨所得功德。何以故？须菩提！以诸菩萨不受福德故。」须菩提白佛言：「世尊！云何菩萨不受福德？」「须菩提！菩萨所作福德，不应贪著。是故说不受福德。」

## 原文

「须菩提！若菩萨以满恒河沙等世界七宝持用布施；若复有人，知一切法无我，得成于忍，此菩萨胜前菩萨所得功德。何以故？须菩提！以诸菩萨不受福德故。」须菩提白佛言：「世尊！云何菩萨不受福德？」「须菩提！菩萨所作福德，不应贪著。是故说不受福德。」

## 朗读停顿

「须菩提！ / 若菩萨以满恒河沙等世界七宝持用布施；若复有人，知一切法无我，得成于忍，此菩萨胜前菩萨所得功德。 / 何以故？ / 须菩提！ / 以诸菩萨不受福德故。 / 」须菩提白佛言：「世尊！ / 云何菩萨不受福德？ / 」「须菩提！ / 菩萨所作福德，不应贪著。 / 是故说不受福德。 / 」

## 关键词链

知一切法无我 → 得成于忍 → 不受福德

## 句义

知法无我而成于忍，是把空义落到能承受、能实践；不受福德不是拒绝善果，而是不贪著、不开一张自我账单。

## 段落作用

[筋] 把无我落实为能忍、能行、而不贪著福德的实践。
