# 法界通化分第十九

「须菩提！于意云何？若有人满三千大千世界七宝，以用布施，是人以是因缘，得福多不？」「如是，世尊！此人以是因缘，得福甚多。」「须菩提！若福德有实，如来不说得福德多；以福德无故，如来说得福德多。」

## 原文

「须菩提！于意云何？若有人满三千大千世界七宝，以用布施，是人以是因缘，得福多不？」「如是，世尊！此人以是因缘，得福甚多。」「须菩提！若福德有实，如来不说得福德多；以福德无故，如来说得福德多。」

## 朗读停顿

「须菩提！ / 于意云何？ / 若有人满三千大千世界七宝，以用布施，是人以是因缘，得福多不？ / 」「如是，世尊！ / 此人以是因缘，得福甚多。 / 」「须菩提！ / 若福德有实，如来不说得福德多；以福德无故，如来说得福德多。 / 」

## 关键词链

福德无实 → 法界通化

## 句义

福德依因缘成立，却无一个自存的福德实体。空不是取消因果，而是让‘我的功劳’不再成为牢不可破的所有权。

## 段落作用

[筋] 说明福德因缘成立，却不因此成为固定实体；空不取消因果，而是解除实执。
